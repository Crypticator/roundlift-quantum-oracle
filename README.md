# From Correctness to the Quantum Oracle

**Samir Bouftass · Thèse II and four companion papers**

The twelve-chapter manuscript studies C1-K4-P12-CBD1, the rank-four profile associated with the public name RoundLift. The technical name identifies the scheme throughout the scientific sources. The thesis derives exact rounding and decryption identities and gives conditional security reductions in stated ideal-oracle experiments. Quantitative hardness of the sources and concrete post-quantum security at 128 bits remain open.
