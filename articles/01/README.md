# C1-K4-P12-CBD1: Exact Correctness, Conditional Security, and Reproducible Attack Estimates

Samir Bouftass · Version 1.1 · English.

The paper specifies a rank-four encryption profile over a negacyclic ring with modulus 4096. An exact error identity retains dependent remainders and yields a two-sided bound on averaged worst-message decryption failure. Two joint-distribution hybrids reduce passive security to specified CBD1 Module-LWE sources. The paper gives a scoped classical random-oracle KEM argument and documents two attack-cost model evaluations, including their reproduction status and search limits.
